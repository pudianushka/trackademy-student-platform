# Trackademy 🎓

Trackademy is a student-focused educational and productivity platform designed to help students stay organized during exams and academic preparation.

---

## 🚀 Features

* 📚 Notes organization
* 🗓️ Study planning
* ✅ Productivity-focused design
* 🎯 Student-friendly interface

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Replit AI tool

---

## 🎯 Purpose

Built to help students manage academic work smartly and efficiently.
